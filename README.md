# Betimleme Dedektifleri

5. sınıf Türkçe dersi için etkileşimli betimleme oyunu.

## Cloudflare Workers

`index.html` is the site entry page. It is an unchanged copy of the original game HTML file. The original named file remains in the repository as well.

The repository uses Cloudflare Workers Static Assets. Its asset directory and Worker name are defined in `wrangler.jsonc`; the deployment command is `npx wrangler deploy`.
